# dumbfish

Шахматный движок на Rust с классической оценкой: линейная функция признаков позиции с отдельными весами
для дебюта, миттельшпиля и эндшпиля. Сила и стиль игры настраиваются. Общается с GUI только по протоколу UCI.

## Сборка и запуск

```sh
cargo build --release          # target/release/dumbfish
just build [ref]               # сборка ветки или коммита в target/play/dumbfish, путь для GUI
just uci [ref]                 # то же и сразу UCI в терминале
```

Без аргументов `dumbfish` читает команды UCI со stdin и отвечает в stdout. `dumbfish bench [depth]` ищет до
заданной глубины (по умолчанию 5) на позициях из `engine/bench.epd` и печатает `N nodes M nps`; `N` —
сигнатура версии, одинаковая на любой машине.

## Команды UCI

| Команда | Поведение |
|---|---|
| `uci` | `id name`, `id author`, опции, `uciok` |
| `isready` | `readyok`, в том числе во время поиска |
| `debug on \| off` | в режиме отладки движок отвечает `info string` на `position` (получившийся FEN) и на `go` (понятые ограничения) |
| `register ...` | игнорируется: регистрация не нужна |
| `ucinewgame` | новая позиция и пустая хэш-таблица |
| `position startpos \| fen <fen> [moves ...]` | при ошибке (FEN, нелегальный ход) позиция не меняется, ответ `info string ...` |
| `go` | см. ниже |
| `stop` | прерывает поиск, движок отвечает `bestmove` |
| `ponderhit` | соперник сделал ожидаемый ход: поиск из `go ponder` продолжается на своих часах |
| `setoption name <имя> [value <значение>]` | неизвестная опция или неверное значение — `info string ...` |
| `quit` | прерывает поиск и завершает работу |
| `eval` | нестандартная: таблица вклада каждого ненулевого признака оценки и групп стиля |

`position`, `go`, `ucinewgame`, `setoption` и `eval`, присланные во время поиска, ждут его окончания, как в
Stockfish; прерывают поиск только `stop` и `quit`. Неизвестные слова перед командой пропускаются, как требует
протокол (`joho debug on` включает отладку); строка без известной команды даёт `info string unknown command`.

Параметры `go`:

| Параметр | Значение |
|---|---|
| `depth N`, `nodes N`, `movetime MS` | ограничения глубины, узлов и времени на ход |
| `mate N` | искать, пока не найден мат не более чем в N ходов (без других ограничений — до `stop`) |
| `wtime`, `btime`, `winc`, `binc`, `movestogo` | часы: мягкий лимит `время/ходы + 3/4 добавки` (новая итерация не начинается), жёсткий — втрое больше, оба не больше остатка минус 30 мс |
| `infinite` | без ограничений; `bestmove` только после `stop` |
| `ponder` | поиск в чужое время: часы начинают идти с `ponderhit`, `bestmove` не раньше `ponderhit` или `stop` |
| `searchmoves m1 m2 ...` | выбирать только из этих ходов; нелегальные пропускаются |

## Вывод

После каждой завершённой итерации для каждой линии MultiPV:

```
info depth 9 seldepth 21 multipv 1 score cp 42 wdl 323 500 177 nodes 193734 nps 407876 hashfull 24 tbhits 0 time 474 pv e2e4 e7e5 ...
```

- `score cp N` — оценка в сантипешках со стороны хода; `score mate N` — мат в N ходов (отрицательное — движку).
  Выигрыш по эндшпильным таблицам — `cp 30000` минус число полуходов до взятия или хода пешкой (проигрыш — со
  знаком минус).
- `wdl W D L` — вероятности выигрыша, ничьей и проигрыша в промилле, только при `UCI_ShowWDL`.
- `nodes`, `nps` — по всем потокам; `hashfull` — заполненность хэш-таблицы в промилле; `tbhits` — удачные
  обращения поиска к эндшпильным таблицам.
- Через 3 секунды поиска перед каждым ходом из корня: `info depth D currmove <ход> currmovenumber N`.
- `pv` — главная вариация; линии MultiPV идут от лучшей.

В конце — `bestmove <ход> [ponder <ход>]`; если ходов нет, `bestmove 0000`.

## Опции

| Опция | Тип | По умолчанию | Значения | Описание |
|---|---|---|---|---|
| `Hash` | spin | 16 | 1–65536 | размер хэш-таблицы, МБ |
| `Clear Hash` | button | | | очистить хэш-таблицу |
| `Threads` | spin | 1 | 1–256 | потоки поиска (Lazy SMP) |
| `MultiPV` | spin | 1 | 1–256 | сколько лучших линий показывать |
| `Ponder` | check | false | | разрешение думать в чужое время; само обдумывание включает `go ponder` |
| `UCI_ShowWDL` | check | false | | добавлять `wdl` к оценке |
| `UCI_Chess960` | check | false | | шахматы Фишера: рокировка записывается как взятие королём своей ладьи (`e1h1`); FEN в X-FEN или Shredder-FEN принимается в любом режиме |
| `SyzygyPath` | string | `<empty>` | каталоги через `:` | эндшпильные таблицы Syzygy (`.rtbw`, `.rtbz`); ответ — `info string found N tablebases, up to K pieces`. Если позиция в корне есть в таблицах, ищутся только ходы с лучшим результатом (кратчайший выигрыш, самый долгий проигрыш), иначе поиск берёт результат из таблиц после взятий и ходов пешкой. При `Skill Level` ниже 20 не используются |
| `Skill Level` | spin | 20 | 0–20 | ниже 20: лимит узлов `256 << (уровень / 2)` и случайная добавка до `15 × (20 − уровень)` cp к оценкам ходов из корня; поиск в один поток |
| `Style` | combo | balanced | balanced, aggressive, defensive, positional, materialistic | пресет из `engine/styles.txt`: множители групп и `Contempt` |
| `Style Material` | spin | 100 | 0–300 | множитель группы, % |
| `Style Positional` | spin | 100 | 0–300 | |
| `Style Pawns` | spin | 100 | 0–300 | |
| `Style Mobility` | spin | 100 | 0–300 | |
| `Style King Attack` | spin | 100 | 0–300 | |
| `Style King Defense` | spin | 100 | 0–300 | |
| `Contempt` | spin | 0 | −200–200 | цена ничьей в сантипешках для стороны, ходящей в корне; отрицательная — движок ищет ничью |

`UCI_EngineAbout` (string) — сведения о движке для GUI; присланное значение игнорируется.

`Style` задаёт все шесть множителей и `Contempt` сразу; опции групп и `Contempt`, присланные после, меняют
отдельные значения.

## Данные

| Файл | Содержимое |
|---|---|
| `engine/weights.txt` | веса признаков оценки по фазам, подбираются `dumbfish-tuner` |
| `engine/styles.txt` | пресеты стиля |
| `engine/wdl.txt` | модель выигрыш/ничья/проигрыш, подбирается `dumbfish-tools wdl` |
| `engine/bench.epd` | позиции `bench` |

Файлы встраиваются в бинарник при сборке. Правила разработки — в `CLAUDE.md`.

Таблицы Syzygy до 5 фигур (около 1 ГБ):

```sh
mkdir -p target/syzygy && cd target/syzygy
curl -fsSL http://tablebase.sesse.net/syzygy/3-4-5/ | grep -oE 'K[A-Za-z]*v[A-Za-z]*\.rtb[wz]' | sort -u \
  | xargs -I{} curl -fsSO http://tablebase.sesse.net/syzygy/3-4-5/{}
```
